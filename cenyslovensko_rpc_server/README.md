# CenySlovensko RPC Server

Rust JSON-RPC server module that exposes CenySlovensko APIs over stdin/stdout for language bindings. The crate is
structured with ports-and-adapters to support adding more RPC APIs over time.

> [!NOTE]
> Intended to be used by in-process or local bindings (Python, Ruby, Node.js) through JSON-RPC calls.

> [!IMPORTANT]
> This project is not affiliated with or endorsed by CenySlovensko. It is an independent implementation.
