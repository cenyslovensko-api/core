# CenySlovensko Rust APIs

Rust APIs for CenySlovensko, a platform that provides price information for various products in Slovakia. This
repository contains the source code and documentation for the APIs, allowing developers to integrate price data into
their applications.

> [!NOTE]
> Find the official CenySlovensko website at [https://www.cenyslovensko.sk](https://www.cenyslovensko.sk) for more
information.


> [!IMPORTANT]
> This project is not affiliated with or endorsed by CenySlovensko. It is an independent implementation of APIs for
accessing price data.
